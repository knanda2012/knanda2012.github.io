# Krishnananda C P — Research Website Starter

A mobile-friendly research portfolio using plain HTML, CSS and JavaScript. No installation, building, packages, framework or Git commands required. The flow animation and research-card illustrations are **conceptual**, not real experimental or simulation data.

## Publish with GitHub Pages

1. On GitHub, select **+ > New repository**.
2. Name it **YOUR-GITHUB-USERNAME.github.io**, replacing YOUR-GITHUB-USERNAME with your actual account username (in lowercase). Set the repository to **Public**, enable **Add a README file**, and create it.
3. Download the ZIP supplied by ChatGPT and **extract** it on your computer.
4. Open the repository's **Code** tab, select **Add file > Upload files**. Drag in `index.html`, `styles.css`, `script.js` (optionally replace the README.md too). The files must appear at the TOP LEVEL of the repository, not inside a folder. Click **Commit changes**.
5. Go to **Settings > Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
6. Open **https://YOUR-GITHUB-USERNAME.github.io/**. The first deployment may take several minutes.

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## Personalize next

- `index.html`: edit your introduction and research descriptions, and add publication links only after confirming your metadata.
- `index.html`: replace the placeholder contact button with your preferred email and public research profiles; make sure every public claim is accurate.
- `index.html`: replace decorative SVG illustrations with your own approved experimental photographs, plots and figures, using an `assets/` folder.
- `styles.css`: adjust the colors in `:root` and the section styling.
- `script.js`: controls the conceptual particle-flow artwork and frequency buttons. It is **not** a COMSOL calculation or a comparison with measured data.
- Add a real CV PDF to the repository only if you want it published publicly; then link to it from `index.html`.
- Check the site on mobile. Use alt text for scientific figures, include units and figure captions, and avoid sharing unpublished confidential material without approval.

## Local preview

Double-click `index.html` on your computer; it works in a browser. You can also serve the folder from a local HTTP server if desired. An internet connection is used for Google Fonts, but system-font fallbacks are available.
